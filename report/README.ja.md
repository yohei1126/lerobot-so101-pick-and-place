# 提出用レポート（PDF）作成手順

本課題の公式提出物は PDF 形式の文書のみである。原稿の正本は本ディレクトリ内の Markdown ファイル（`説明資料_PAI最終課題_yohei1126.md`）として管理し、ビルドスクリプトを通じて PDF を出力する。

## 提出ファイル仕様

提出ファイル名は講義仕様に基づき、以下のように命名する。

```text
説明資料_PAI最終課題_yohei1126.pdf
```

- OmniCampus アカウント名: `yohei1126`
- 匿名性の確保: 氏名、所属機関、メールアドレスなどの個人識別情報は記載しない。

## PDF のビルド手順

本ビルド処理は、内部で `pandoc` および `typst`（`--pdf-engine=typst`）を利用する。

```bash
# リポジトリルートからの実行
./scripts/build_report_pdf.sh yohei1126
```

実行後、`report/説明資料_PAI最終課題_yohei1126.pdf` に PDF が生成される（Git 管理対象外）。

既定では [`説明資料_PAI最終課題_yohei1126.md`](説明資料_PAI最終課題_yohei1126.md) が入力原稿として使用される。別の原稿ファイルを指定する場合は、第2引数にファイルパスを渡す。

```bash
./scripts/build_report_pdf.sh yohei1126 path/to/draft.md
```

## 提出前チェックリスト（個人情報保護）

提出前に以下の項目を点検し、匿名性が担保されていることを確認する。

- [ ] 表紙および本文中に氏名、所属、メールアドレス、電話番号、学生証番号の記載がないこと
- [ ] 掲載図表やターミナルのスクリーンショットに個人環境のユーザ名やメールアドレスが映り込んでいないこと
- [ ] OmniCampus アカウント名（`yohei1126`）以外の個人識別子が含まれていないこと
- [ ] 生成された PDF のファイル名が命名規則に合致していること
- [ ] リポジトリの公開 README およびコミット履歴に個人連絡先が含まれていないこと
